# Сегментация локальных возвышенностей по оптическим аэроснимкам

Модуль предназначен для обучения и применения нейросетевой модели бинарной семантической сегментации локальных возвышенностей по трехканальным оптическим изображениям (RGB).

Модуль расположен в подкаталоге `elevation_segmentation` репозитория `Space_FIT`. Запуск может производиться как кнопкой **Run** в среде PyCharm при открытом файле `elevation_segmentation/train.py`, так и через интерфейс командной строки из корня проекта: `python -m elevation_segmentation.train`.

---

## 1. Параметры конфигурации (`config.json`)

Файл `elevation_segmentation/config.json` содержит все гиперпараметры обучения, архитектуры, предобработки и загрузки весов:

| Параметр | Тип | Назначение |
|---|---|---|
| `dataset_root` | `string` | Путь к корневому каталогу датасета (содержит каталоги `train` и `val` с подкаталогами `images` и `masks` либо файл `manifest.jsonl`). Относительные пути разрешаются относительно корня проекта `Space_FIT`. |
| `output_dir` | `string` | Каталог для сохранения результатов: чекпоинтов (`best.pt`, `last.pt`), журналов обучения, метрик, визуализаций и записей TensorBoard. |
| `architecture` | `string` | Название архитектуры из библиотеки `segmentation_models_pytorch` (по умолчанию `DeepLabV3Plus`). Поддерживаются также `Unet`, `UnetPlusPlus` и другие совместимые архитектуры. |
| `encoder_name` | `string` | Имя базовой сети-энкодера (по умолчанию `resnet34`). |
| `encoder_weights` | `string` / `null` | Источник начальных весов энкодера (`"imagenet"` для предобученных весов ImageNet либо `null` для случайной инициализации). При новом обучении энкодер сначала инициализируется этими весами, после чего поверх совместимых слоев могут быть загружены веса из `pretrained_path`. |
| `crop_size` | `int` | Пространственный размер сторон обучающих вырезок в пикселях (по умолчанию `512`). Все геометрические аугментации синхронно приводят изображение и маску к этому размеру. |
| `crops_per_image` | `int` | Число случайных вырезок, формируемых из каждого снимка обучающей выборки за одну эпоху (по умолчанию `12`). |
| `positive_crop_probability` | `float` | Вероятность центрирования вырезки на фрагменте, содержащем хотя бы один пиксель возвышенности (значение `1`). Позволяет компенсировать пространственный дисбаланс классов. |
| `batch_size` | `int` | Размер батча для обучающего и валидационного загрузчиков данных (`DataLoader`). |
| `accumulation_steps` | `int` | Число шагов накопления градиентов перед выполнением шага оптимизатора (`optimizer.step()`). Эффективный размер батча равен `batch_size * accumulation_steps`. |
| `epochs` | `int` | Полное число эпох обучения. |
| `encoder_lr` | `float` | Базовая скорость обучения энкодера при отключенном планировщике (`"scheduler": "none"`). |
| `decoder_lr` | `float` | Базовая скорость обучения декодера и сегментационной головы при отключенном планировщике (`"scheduler": "none"`). |
| `weight_decay` | `float` | Коэффициент L2-регуляризации параметров в оптимизаторе `AdamW`. |
| `pos_weight` | `float` | Весовой множитель положительного класса возвышенностей для функции потерь `BCEWithLogitsLoss`. |
| `dice_weight` | `float` | Весовой коэффициент Dice-составляющей в комбинированной функции потерь: `(1 - dice_weight) * BCE + dice_weight * Dice`. |
| `threshold` | `float` | Порог вероятности бинаризации логитов при валидации и инференсе (по умолчанию `0.5`). |
| `tile_size` | `int` | Размер тайла при скользящем окне на валидации и инференсе полноразмерных изображений. |
| `overlap` | `int` | Размер взаимного перекрытия соседних тайлов в пикселях для сглаживания граничных артефактов. |
| `freeze_batchnorm` | `bool` | Флаг фиксации статистик слоев пакетной нормализации (`BatchNorm`). При малых размерах батча рекомендуется выставлять `true`. |
| `amp` | `bool` | Флаг использования автоматической смешанной точности (`torch.cuda.amp.autocast`) при вычислениях на графическом процессоре (CUDA). |
| `num_workers` | `int` | Количество параллельных процессов загрузки данных в `DataLoader`. |
| `seed` | `int` | Базовое начальное число генераторов псевдослучайных чисел для воспроизводимости выборок и аугментаций. |
| `save_every_steps` | `int` | Периодичность сохранения рабочего чекпоинта `last.pt` (в выполненных шагах оптимизатора). |
| `device` | `string` | Целевое вычислительное устройство (`"auto"`, `"cuda"`, `"cpu"`). |
| `normalization_mean` | `list` | Математические ожидания по каналам RGB для стандартизации входных изображений. |
| `normalization_std` | `list` | Стандартные отклонения по каналам RGB для стандартизации входных изображений. |
| `pretrained_path` | `string` / `null` | Путь к файлу чекпоинта (`.pt`) для загрузки весов или продолжения обучения. Разрешается относительно корня проекта. |
| `same_num_classes` | `bool` | Флаг совпадения структуры и назначения выходной головы. При `true` загружаются все слои модели, включая голову. При `false` загружаются только общие слои, а выходная голова инициализируется заново. |
| `resume_training` | `bool` | Флаг продолжения прерванного обучения. При `true` полностью восстанавливаются веса модели, состояния оптимизатора, планировщика, AMP scaler, номер эпохи, шаг батча и генераторы случайных чисел. |
| `scheduler` | `string` | Тип планировщика скорости обучения: `"onecycle"` (`OneCycleLR`) либо `"none"` (постоянная скорость обучения). |
| `encoder_max_lr` | `float` | Пиковая скорость обучения энкодера для планировщика `OneCycleLR`. |
| `decoder_max_lr` | `float` | Пиковая скорость обучения декодера и головы для планировщика `OneCycleLR`. |
| `onecycle_pct_start` | `float` | Доля общего цикла обучения, отводимая на фазу нарастания скорости обучения (warmup). |
| `onecycle_div_factor` | `float` | Делитель начальной скорости обучения для `OneCycleLR` (`initial_lr = max_lr / div_factor`). |
| `onecycle_final_div_factor` | `float` | Делитель конечной скорости обучения для `OneCycleLR` (`min_lr = initial_lr / final_div_factor`). |

## 2. Режимы загрузки модели и продолжения обучения

Взаимодействие параметров `pretrained_path`, `same_num_classes` и `resume_training`:

| Режим | Настройки в `config.json` | Поведение системы |
|---|---|---|
| **Новое обучение с нуля** | `"pretrained_path": null`<br>`"resume_training": false` | Инициализация весов, определяемая параметром `encoder_weights` (ImageNet или случайная). Обучение начинается с 1-й эпохи с новым состоянием оптимизатора и планировщика. |
| **Новое обучение с загрузкой всей модели** | `"pretrained_path": "runs/.../best.pt"`<br>`"same_num_classes": true`<br>`"resume_training": false` | Строгая проверка архитектуры и загрузка всех весов, включая выходную голову сегментации. Обучение начинается с 1-й эпохи с новым состоянием оптимизатора и планировщика. |
| **Дообучение с заменой головы** | `"pretrained_path": "runs/.../best.pt"`<br>`"same_num_classes": false`<br>`"resume_training": false` | Сначала энкодер инициализируется весами ImageNet (если задан `encoder_weights`), затем поверх загружаются совпадающие по имени и размерам тензоры. Выходная голова инициализируется заново. Обучение с 1-й эпохи. |
| **Продолжение прерванного процесса** | `"pretrained_path": "runs/.../last.pt"`<br>`"same_num_classes": true`<br>`"resume_training": true` | Полное восстановление состояния: веса модели, состояние оптимизатора, шаги планировщика, состояние AMP scaler, эпоха, номер батча, метрики и генераторы случайных чисел. |

### Смена назначения классов при сохранении их количества

Если изменилась семантическая интерпретация классов (например, бинарная маска обучалась на водоемах, а теперь обучается на возвышенностях), выходную голову необходимо инициализировать заново, выставив `"same_num_classes": false`, даже если количество выходных каналов (1 канал логитов) осталось прежним.

### Недопустимые сочетания параметров

Попытка установить `"resume_training": true` при `"pretrained_path": null` либо при `"same_num_classes": false` вызывает ошибку конфигурации `ValueError` с информативным пояснением.

Чекпоинты устаревшего формата с планировщиком `ReduceLROnPlateau` поддерживаются только как источник весов при `"resume_training": false`. При попытке продолжить обучение (`"resume_training": true`) по такому чекпоинту выдается сообщение о невозможности продолжения устаревшего расписания.

## 3. Планировщик скорости обучения (OneCycleLR и постоянная скорость)

Управление скоростью обучения осуществляется через параметр `scheduler`:

### Режим OneCycleLR (`"scheduler": "onecycle"`)

Планировщик `torch.optim.lr_scheduler.OneCycleLR` синхронизирован с прогрессом обучения внутри каждой эпохи:
- Число шагов в эпохе (`steps_per_epoch`) рассчитывается по фактическому количеству выполненных обновлений оптимизатора с учетом `accumulation_steps` и возможной неполной группы в конце эпохи.
- Вызов `scheduler.step()` выполняется непосредственно после обновления весов оптимизатором.
- Механизм автоматически учитывает пропуск шага оптимизатора, возникающий при переполнении градиентов в автоматической смешанной точности (AMP GradScaler).

Начальная скорость обучения определяется формулой:
$$\text{initial\_lr} = \frac{\text{max\_lr}}{\text{onecycle\_div\_factor}}$$

Поэтому параметры `encoder_lr` и `decoder_lr` при `"scheduler": "onecycle"` не определяют начальный LR и не входят в противоречие с настройками `encoder_max_lr` и `decoder_max_lr`.

Пример конфигурации:
```json
{
  "scheduler": "onecycle",
  "encoder_max_lr": 0.00001,
  "decoder_max_lr": 0.0001,
  "onecycle_pct_start": 0.1,
  "onecycle_div_factor": 10.0,
  "onecycle_final_div_factor": 10000.0
}
```

### Режим постоянной скорости обучения (`"scheduler": "none"`)

В данном режиме скорость обучения остается постоянной на протяжении всего процесса и определяется базовыми значениями `encoder_lr` и `decoder_lr`:
```json
{
  "scheduler": "none",
  "encoder_lr": 0.00003,
  "decoder_lr": 0.0003
}
```

## 4. Аугментации данных

Обучающая выборка обрабатывается набором синхронных пространственных и фотометрических аугментаций, заимствованным из базового модуля проекта:
1. `SyncRandomBrightnessContrastTarget`
2. `SyncRandomHorizontalFlip`
3. `SyncRandomVerticalFlip`
4. `SyncRotate360_plus(resolution=crop_size, fill_mask=255)`
5. `RandomGridDistortion(fill_mask=255)`
6. `RandomElasticTransform(fill_mask=255)`
7. `TrickyResize_UpDwn(resolution=crop_size, minmax_size_up=[117, 200])`
8. `AffineAugmentation(p=0.75, translate_percent=(-0.5, 0.5), scale=(0.7, 1.1), fill_mask=255)`
9. `SyncResize(crop_size)`
10. `SyncToTensor()`
11. `RandomNoiseSP()`

Порядок преобразований: первые 8 аугментаций перемешиваются в случайном порядке перед каждым кадром (`n_e_augs_shuffle`), а последние три (`SyncResize`, `SyncToTensor`, `RandomNoiseSP`) выполняются строго в фиксированной последовательности.

### Свойства обработки масок
- Пространственные преобразования применяются строго синхронно к изображению и маске.
- Интерполяция масок выполняется исключительно методом ближайшего соседа (`NEAREST`), что исключает появление промежуточных значений.
- Значения маски `0` (фон), `1` (возвышенность) и `255` (область игнорирования) сохраняются без изменений.
- Области за границами исходного кадра, возникающие при поворотах, аффинных сдвигах и упругих деформациях, заполняются значением `255`.
- Фотометрические искажения и импульсный шум применяются только к изображению.
- Преобразование RGB в диапазон $[0, 1]$ и стандартизация выполняются один раз.
- Выход загрузчика: тензор изображения `float32 [3, crop_size, crop_size]` и тензор маски `int64 [crop_size, crop_size]`.

### Особенности масштаба и геометрии
Исходные аэрокосмические снимки Sentinel-2 обладают пространственным разрешением 10 м/пиксель. Случайные геометрические аугментации искусственно модифицируют геометрию обучающих примеров для повышения обобщающей способности нейронной сети при распознавании форм рельефа.

Случайные аугментации применяются исключительно на этапе обучения (`is_train=True`). Валидационная выборка обрабатывается только детерминированным приведением к тензору и нормализацией. Детерминизм генераторов псевдослучайных чисел обеспечивается привязкой к кортежу `(seed, epoch, sample_index)`.

## 5. Запуск в PyCharm и командной строке

### Запуск кнопкой Run в PyCharm
1. Откройте файл `elevation_segmentation/train.py` в среде PyCharm.
2. Нажмите сочетание клавиш **Shift + F10** либо зеленую кнопку **Run** на панели инструментов.
3. Дополнительных параметров командной строки указывать не требуется:
   - Файл конфигурации по умолчанию загружается из каталога модуля (`elevation_segmentation/config.json`).
   - Относительные пути (`dataset_root`, `output_dir`, `pretrained_path`) автоматически разрешаются относительно корня проекта `Space_FIT` независимо от рабочей директории PyCharm.
   - Скрипт защищен конструкцией `if __name__ == "__main__":`.
   - В консоль выводится информационный баннер с выбранным режимом, абсолютными путями к конфигу, датасету, чекпоинту и каталогу вывода.

### Запуск через консоль из корня проекта

Запуск со стандартным конфигурационным файлом:
```bash
python -m elevation_segmentation.train
```

Запуск с явным указанием путей и параметров:
```bash
python -m elevation_segmentation.train \
  --config elevation_segmentation/config.json \
  --data "/media/workerfit/SP PHD U3/ТГУ/Космос/elevation_dataset/dataset_250" \
  --output runs/elevation_resnet34_512
```

## 7. Инференс и тестирование

Для применения обученной модели к новым оптическим изображениям используется модуль `elevation_segmentation/inference.py`:

```bash
python -m elevation_segmentation.inference \
  --checkpoint runs/elevation_resnet34_512/best.pt \
  --image /path/to/image.png \
  --output prediction_dir
```

Или программный вызов:
```python
import numpy as np
from PIL import Image
from elevation_segmentation.inference import ElevationPredictor

predictor = ElevationPredictor("runs/elevation_resnet34_512/best.pt", device="auto")
rgb = np.array(Image.open("image.png").convert("RGB"))
mask = predictor.predict(rgb)
```

Запуск автоматических тестов модуля:
```bash
python -m unittest elevation_segmentation.test_module -v
```
