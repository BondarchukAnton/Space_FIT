# Датасет landcoverai — семантическая сегментация ортофотопланов (Польша)

Датасет сформирован на основе ортофотопланов аэросъёмки территории Польши (исходник — [landcover.ai](https://landcover.ai.linuxpolska.com/)). Задача: семантическая сегментация 5 классов (фон, здания, лес, вода, дороги).

> Документация сформирована автоматически скриптом [`analyze_dataset.py`](analyze_dataset.py) (результаты анализа — [`dataset_analysis.json`](dataset_analysis.json)) и сверена с описанием владельца датасета.

---

| Параметр | Значение |
|---|---|

## 2. Структура каталогов

```
landcoverai/
├── images/          # 41 исходный ортофотоплан, формат GeoTIFF (RGB, uint8)
├── masks/           # 41 исходная маска, формат GeoTIFF (1 канал, uint8, значения 0–4)
├── split_images/    # 10 674 тайла 512×512, JPG (RGB) — ВСЕ тайлы всех листов
├── split_masks/     # 10 674 тайла масок 512×512, PNG (RGB, серые значения 0–4)
├── train_images/    # 8 802 JPG — обучающая выборка
├── train_masks/     # 8 802 PNG — маски обучающей выборки
├── test_images/     # 3 204 JPG — тестовая выборка
├── test_masks/      # 3 204 PNG — маски тестовой выборки
├── add_image/       # 1 332 JPG — дополнительные тайлы, ДОБАВЛЕННЫЕ в train
├── add_mask/        # 1 332 PNG — их маски
├── train.txt        # 7 470 имён тайлов (без расширения) — основная часть train
├── test.txt         # 1 602 имён тайлов — основная часть test
├── val.txt          # 1 602 имён тайлов — вторая часть test (совпадает с val)
├── val (копия).txt  # служебный файл (ссылка на источник)
├── split.py, splitnew.py, splitnew_2.py  # скрипты нарезки тайлов
└── analyze_dataset.py  # скрипт анализа датасета
```

### Связи между каталогами

- `split_images/` + `split_masks/` — **полный набор** всех тайлов (10 674).
- `train_images/` = тайлы из `train.txt` (7 470) + тайлы из `add_image/` (1 332) = 8 802.
- `test_images/` = тайлы из `test.txt` (1 602) + тайлы из `val.txt` (1 602) = 3 204.
- `train ∪ test = 12 006` — на 1 332 больше, чем `split` (10 674), т.к. `add_image/` — это **дополнительные** тайлы, отсутствующие в `split_*` (нарезанные с краёв листов, см. логику `splitnew_2.py`).
- `train ∩ test = ∅`.
- Для каждого изображения существует ровно одна маска и наоборот (проверено, 0 несовпадений).

## 3. Именование файлов

| Тип | Шаблон | Пример |
|---|---|---|
| Исходный снимок | `{лист}.tif` | `M-33-20-D-c-4-2.tif` |
| Исходная маска | `{лист}.tif` | `M-33-20-D-c-4-2.tif` |
| Тайл изображения | `{лист}_{индекс_тайла}.jpg` | `M-33-20-D-c-4-2_101.jpg` |
| Тайл маски | `{лист}_{индекс_тайла}_m.png` | `M-33-20-D-c-4-2_101_m.png` |

- `{лист}` — код топографического листа (M/N — полушарие/зона, далее координатная сетка, напр. `M-33-20-D-c-4-2`).
- `{индекс_тайла}` — порядковый номер тайла при нарезке (0, 1, 2, …) — **не** координаты.
- Маска к тайлу `X.jpg` — `X_m.png` (суффикс `_m`).
- В `.txt`-файлах перечислены имена тайлов **без расширения** (например, `M-33-20-D-c-4-2_101`).

## 4. Форматы и параметры файлов

### 4.1 Исходные снимки (`images/`)

| Параметр | Значение |
|---|---|
| Формат | GeoTIFF (`.tif`) |
| Режим | RGB, 3 канала |
| Глубина | 8 бит (uint8), значения 0–255 |
| Размер | **33 листа**: ~8 351–9 243 × 9 289–9 715 px (0,25 м/пикс) |
| | **8 листов**: ~4 113–4 352 × 4 672–4 750 px (0,50 м/пикс) |
| Примечание | Размеры всех 41 листа **разные** (у каждого свой размер) |

### 4.2 Исходные маски (`masks/`)

| Параметр | Значение |
|---|---|
| Формат | GeoTIFF (`.tif`) |
| Режим | **L (1 канал)**, uint8 |
| Значения | **0–4** — индексы классов (не RGB-цвета!) |
| Размер | идентичен соответствующему снимку |

### 4.3 Тайлы (`split_*`, `train_*`, `test_*`, `add_*`)

| Параметр | Изображения | Маски |
|---|---|---|
| Формат | JPEG (`.jpg`) | PNG (`.png`) |
| Режим | RGB, 3 канала | RGB, 3 канала (значения продублированы: `(v, v, v)`) |
| Глубина | uint8, 0–255 | uint8, **0–4** |
| Размер | **512 × 512 px** (все без исключения) | **512 × 512 px** |

> ⚠️ **Важно:** маски хранят **индексы классов 0–4**, а не RGB-цвета палитры. При загрузке маски для обучения берите **один канал** (например, `mask[..., 0]`) и используйте значения как целочисленные индексы.

## 5. Классы и палитра

| Индекс | Класс (RU) | Класс (EN) | Описание | Цвет палитры (RGB) | Hex |
|---|---|---|---|---|---|
| 0 | Фон / Прочее | Background | Поля, луга, пашни, открытый грунт и все непокрытые разметкой объекты | (0, 0, 0) | `#000000` |
| 1 | Здания | Building | Жилые, хозяйственные и промышленные постройки, дома | (255, 0, 0) | `#FF0000` |
| 2 | Лесной массив | Woodland | Сомкнутые леса, парки, древесные массивы и рощи | (0, 255, 0) | `#00FF00` |
| 3 | Водоёмы | Water | Реки, озёра, водохранилища, пруды, протоки | (0, 0, 255) | `#0000FF` |
| 4 | Дороги | Road | Асфальтированные, бетонные и грунтовые дороги | (255, 255, 0) | `#FFFF00` |

- Палитра используется **только для визуализации** (индекс → цвет). В самих файлах масок хранятся индексы 0–4.
- Проверено: во всех масках (и исходных TIF, и тайловых PNG) встречаются **только** значения 0–4, других значений нет.
- Класс 3 (Water) отсутствует в части листов (напр., `M-33-7-A-d-2-3` содержит только 0, 1, 2, 4) — состав классов зависит от территории листа.

## 6. Масштаб (разрешение)

| Разрешение | Кол-во листов | Размер в пикселях |
|---|---|---|
| 0,25 м/пикс (25 см/пикс) | 33 | ~8 351–9 243 × 9 289–9 715 |
| 0,50 м/пикс (50 см/пикс) | 8 | ~4 113–4 352 × 4 672–4 750 |

- Тайлы 512×512 px соответствуют площади **128×128 м** (для 0,25 м/пикс) или **256×256 м** (для 0,50 м/пикс).
- ⚠️ В одном наборе тайлов (train/test) **смешаны тайлы обоих разрешений** — при обучении это стоит учитывать (разный масштаб объектов).

---



### Баланс классов (ориентировочно, по выборке тайлов)

- Фон (0): ~70–99% пикселей в тайле
- Здания (1): ~0–30%
- Лес (2): ~0–10%
- Вода (3): ~0–5% (отсутствует во многих тайлах)
- Дороги (4): ~0–8%
