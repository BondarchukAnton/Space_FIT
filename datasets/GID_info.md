# Датасет GID (GF-2) — справочное описание

> Спутниковые мультиспектральные изображения GF-2 (Gaofen-2) с масками семантической сегментации.
> Источник: проект *Five-Billion-Pixels* / GID.
> - https://x-ytong.github.io/project/GID.html
> - https://x-ytong.github.io/project/Five-Billion-Pixels.html
> - https://paperswithcode.com/dataset/gid

Файлы в этой папке — **8-битные** изображения и **цветовые** маски (5 классов).
Все характеристики ниже получены прямым анализом файлов (`rasterio`), а не только по readme.

---

## 1. Структура папки

| Папка | Содержимое | Кол-во файлов |
|-------|-----------|---------------|
| `Image_8bit_NirRGB/` | Изображения (8-bit, 4 канала) | **130** |
| `Annotation/` | Маски-аннотации (цветовые, 3 канала) | **130** |
| `test_images/` | Тестовые изображения | **20** |
| `test_Annotation/` | Тестовые маски | **20** |
| `readme (important).txt` | Описание (схема на 24 класса — **не совпадает** с реальными масками) | — |
| `readme.txt` | Описание (схема на 5 классов — **совпадает** с реальными масками) | — |

**Итого: 150 изображений + 150 масок** (130 обучающих + 20 тестовых).

### Соответствие «изображение ↔ маска»
Имя маски = имя изображения + суффикс `_5label`:
```
Image_8bit_NirRGB/GF2_PMS2__L1A0001396040-MSS2.tif
Annotation/GF2_PMS2__L1A0001396040-MSS2_5label.tif
```
Проверено: **все 130 обучающих и все 20 тестовых пар совпадают** (нет «сирот» ни с одной стороны).

> ⚠️ В `readme (important).txt` упоминается папка `Coordinate` (координаты) и 16-битные
> изображения `Image_16bit_BGRNir` — **в этой папке их нет**. Есть только 8-битные.

## 2. Изображения (`Image_8bit_NirRGB/`, `test_images/`)

| Параметр | Значение |
|----------|----------|
| Формат | GeoTIFF (`GTiff`), сжатие `packbits`, `interleave=pixel` |
| Размер | **7300 × 6908** пикселей (ширина × высота) — одинаковый у всех 150 файлов |
| Каналов | **4** |
| Тип данных | `uint8` |
| Диапазон значений | **0 … 255** |
| CRS / гео-трансформ | **отсутствуют** (только единица; координат нет) |

### Порядок каналов
По `readme.txt` порядок: **Nir, R, G, B** (отсюда имя папки `NirRGB`).

> ⚠️ **Важное замечание (измерено):** 4-й канал (B по readme) — **константа 255** во всех
> проверенных файлах (min = max = 255). Это либо насыщенный/заполненный канал, либо
> фактическая маска валидности (255 = валидный пиксель). **Проверьте, какой именно канал
> вам нужен, прежде чем использовать 4-й канал как «синий».**

### Как получать RGB (конвенция, используемая в проекте)
Первый канал (Nir) отбрасывается, берутся каналы 2–4:
```python
from PIL import Image
import numpy as np
from rasterio import open as rio_open

def load_rgb(path):
    with rio_open(path) as src:
        arr = src.read()          # (4, H, W) = [Nir, R, G, B]
    rgb = arr[1:]                 # (3, H, W) = [R, G, B]
    return Image.fromarray(np.ascontiguousarray(rgb.transpose(1, 2, 0)))
```
Эквивалентно исходной записи: `Image.fromarray(imread(path)[:, :, 1:])`.

## 3. Аннотации (`Annotation/`, `test_Annotation/`)

| Параметр | Значение |
|----------|----------|
| Формат | GeoTIFF (`GTiff`), сжатие `packbits` |
| Размер | **7300 × 6908** — **1:1 совпадает** с изображением |
| Каналов | **3** (цветовая маска RGB, **не** одноканальный индекс) |
| Тип данных | `uint8` |
| Значения | только `0` и `255` (бинарные цвета) |

> ⚠️ Маски хранятся как **цветовые** (RGB), а не как одноканальные индексы, несмотря на то,
> что `readme` описывает и `Annotation__color`, и `Annotation__index`. В этой папке — **только цветовые**.
> Для обучения «в лоб» цвета нужно преобразовать в индексы классов (см. ниже).

### Классы (5 + unlabeled) — соответствует `readme.txt`
| Индекс | Цвет (R,G,B) | Класс |
|--------|--------------|-------|
| 0 | (0, 0, 0) | unlabeled (фон / не размечено) |
| 1 | (255, 0, 0) | built-up (застройка) |
| 2 | (0, 255, 0) | farmland (пашня) |
| 3 | (0, 255, 255) | forest (лес) |
| 4 | (255, 255, 0) | meadow (луговина) |
| 5 | (0, 0, 255) | water (вода) |

> ⚠️ `readme (important).txt` содержит **другую** схему на 24 класса (цвета вида `200,0,0`,
> `150,250,0` и т.д.). **Реальные маски в этой папке используют 5-классную схему из `readme.txt`**
> (подтверждено прямым подсчётом уникальных цветов). Суффикс `_5label` в именах файлов тоже
> указывает на 5 классов.


## 4. Пространственное разрешение (GSD)
- **Мультиспектральные каналы (RGB + NIR): 4 м / пиксель.**
- **Панхроматический канал: 1 м / пиксель** (в этой папке панхроматика **отсутствует**).

Оценка размера сцены: `7300 px × 4 м ≈ 29.2 км` × `6908 px × 4 м ≈ 27.6 км`.

## 6. Чек-лист / замечания для агента и человека
1. **Размер фиксирован** — все 150 изображений и 150 масок `7300×6908`. Кроп/тайлы не нужны для выравнивания.
2. **Маски — цветовые (RGB)**, а не индексы. Перед обучением преобразуйте цвета → индексы (код в §3).
3. **4-й канал изображений — константа 255.** Не используйте его как «синий» без проверки.
4. **Классов 5 + unlabeled** (схема `readme.txt`). Игнорируйте 24-классную схему из `readme (important).txt` — она не соответствует данным.
5. **Нет гео-координат** (CRS/transform отсутствуют). Для привязки к карте нужны внешние координаты (папка `Coordinate` в этой копии отсутствует).
6. **Нет 16-битных изображений** и панхроматики в этой папке — только 8-бит MSS.
7. **Тестовый набор** — 20 пар в `test_images/` + `test_Annotation/` (список файлов также в readme).
8. **Память:** одно изображение `4×6908×7300×1 байт ≈ 200 МБ`. При загрузке целиком учитывайте RAM; для анализа достаточно читать окна (`rasterio.windows.Window`).
