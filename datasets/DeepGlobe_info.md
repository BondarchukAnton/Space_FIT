# DeepGlobe Land — документация датасета

Сегментация спутниковых снимков по типам землепользования (DeepGlobe Land Use).

- Официальные ссылки: [deepglobe.org](http://deepglobe.org/), [CodaLab competition](https://competitions.codalab.org/competitions/18468), [Papers with Code](https://paperswithcode.com/dataset/deepglobe)
- Пространственное разрешение (GSD): **0.5 м/пиксель** (50 см/пиксель)
- Размер кадра: 2448 × 2448 px → физический размер участка ≈ **1.224 × 1.224 км**

---

## 1. Структура папок

```
DeepGlobe_Land/
├── train/          # 702 пары (sat + mask)
├── valid/          # 101 пара (sat + mask)
├── test/           # 343 sat-изображения, БЕЗ масок (для предсказания)
├── metadata.csv    # таблица соответствия: image_id, split, sat_image_path, mask_path
├── class_dict.csv  # палитра классов (name, r, g, b)
├── info            # ссылки на исходники датасета
└── scripts/
    └── analyze_dataset.py  # скрипт проверки характеристик датасета
```

Именование файлов: `{image_id}_sat.jpg` (снимок) и `{image_id}_mask.png` (маска).
`image_id` — числовой идентификатор (например, `10233`, `129298`).

## 3. Характеристики изображений (проверено скриптом по всем 1146 файлам)

| Параметр | Sat-изображения | Маски |
|----------|-----------------|-------|
| Размер | **2448 × 2448 px** (все файлы) | **2448 × 2448 px** (все файлы) |
| Режим | **RGB** (3 канала) | **RGB** (3 канала) |
| Формат | **JPEG** (`.jpg`) | **PNG** (`.png`) |
| Тип пикселей | 8 бит на канал | 8 бит на канал |
| Диапазон значений | **0–255** (все каналы) | только цвета палитры (см. ниже) |
| Сжатие | с потерями (JPEG) | без потерь (PNG) |

Размеры sat и mask в каждой паре **совпадают** (2448 × 2448).

## 4. Формат аннотации

- Маска — это **RGB-изображение 2448 × 2448 в формате PNG**, где каждый пиксель окрашен в один из 7 цветов палитры (цвет = класс).
- **Важно:** маски в этом датасете — **НЕ одноканальные** (не uint8 с label-значениями). Это RGB-картинки с палитровыми цветами. Для обучения нейросети маски нужно конвертировать в одноканальные label-карты (см. раздел 6).
- В масках встречаются **только** 7 цветов палитры, посторонних цветов нет (проверено по всем 803 маскам).
